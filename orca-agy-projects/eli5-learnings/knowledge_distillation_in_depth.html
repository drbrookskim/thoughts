DARK KNOWLEDGE

어둠 속의 지식:
정답 너머의 상호 정보량.

고양이 사진을 볼 때 정답 레이블은 [고양이: 1.0, 호랑이: 0.0, 자동차: 0.0]입니다. 그러나 훈련된 교사 모델은 [고양이: 0.85, 호랑이: 0.14, 자동차: 0.0001]을 출력합니다. 호랑이가 자동차보다 고양이와 훨씬 닮았다는 이 미세한 상대 확률 정보가 학생 모델의 과적합을 막고 강력한 일반화 성능을 부여합니다.

제프리 힌튼은 이 현상을 '어두운 지식(Dark Knowledge)'이라 명명했습니다.

HISTORICAL TIMELINE

앙상블 압축에서 거대 언어 모델 추론 체인까지.

소형 신경망이 대형 모델의 표상을 학습하는 이론적 태동부터 현대 생성형 AI의 핵심 축으로 안착하기까지의 역사적 전환점입니다.

2006

Buciluǎ & Caruana et al. — 모델 압축(Model Compression)의 탄생

코넬 대학교 연구진은 수백 개의 앙상블 신경망이 가진 방대한 지식을 레이블이 없는 대규모 의사 데이터(Unlabeled Pseudo-data)의 예측값을 사용하여 단일 소형 신경망으로 훈련하는 개념을 최초로 제안했습니다. 복잡한 앙상블 함수를 단순한 네트워크로 근사할 수 있음을 입증한 시초입니다.

2015

Hinton, Vinyals, Dean — "Distilling the Knowledge in a Neural Network"

제프리 힌튼 교수와 구글 연구팀은 '지식 증류(Knowledge Distillation)'라는 용어를 공식화했습니다. Softmax 함수에 온도 매개변수 $T$를 도입하여 교사 모델의 로짓에 숨겨진 '어두운 지식(Dark Knowledge)'을 복원하고, $T^2$ 스케일링 팩터로 그래디언트 크기를 보정한 표준 KD 손실 함수를 확립했습니다.

2015

FitNets (Romero et al.) — 힌트 계층(Hint Layers)과 은닉 표상 증류

요슈아 벤지오 연구팀은 얕고 넓은 모델 대신 '깊고 얇은(Deep and Thin)' 학생 모델을 훈련하기 위해 중간 은닉층(Hint Layer)에 회귀 사영 계층($W_r$)을 배치했습니다. 최종 출력이 아닌 신경망 내부의 잠재 표상을 직접 지도하는 특징 기반 증류(Feature-based KD)의 문을 열었습니다.

2017

Attention Transfer (Zagoruyko & Komodakis) — 시각적 주목 영역 전이

합성곱 계층의 채널 축을 따라 통계적 활성도를 합산하여 2차원 공간 어텐션 맵(Spatial Attention Map)을 추출하고, 학생 모델이 교사와 동일한 이미지 영역에 시선을 집중하도록 유도했습니다. 객체 인식과 컴퓨터 비전 도메인의 전이 효율을 비약적으로 개선했습니다.

2019

DistilBERT (Sanh et al.) — 트랜스포머 언어 모델 압축의 대중화

HuggingFace 연구진은 12계층 BERT의 인코더 레이어를 6개로 절반 축소하면서도 97%의 NLU 벤치마크 성능을 유지하고 추론 속도를 60% 가속했습니다. 삼중 손실 함수(Soft Target Loss + Cosine Embedding Loss + Hard Masked LM Loss)를 적용하여 대형 NLP 모델의 실시간 서빙 지평을 열었습니다.

2024 ~ 2026

LLM 추론 체인(CoT) & Sequence-level On-Policy 지식 증류

단순 토큰 단위 예측을 넘어, 거대 추론 모델(DeepSeek-R1, Claude, GPT-o시리즈)이 생성한 심층 사고 과정(Chain of Thought)과 검증 궤적을 7B~14B 크기의 소형 모델(Qwen-2.5-Distill 등)에 주입하는 패러다임이 확립되었습니다. 역방향 KL 발산(Reverse KL)을 활용한 온폴리시(On-policy) 증류로 환각을 억제하고 수학·코딩 추론 역량을 온디바이스로 이식합니다.

PILLAR 1: RESPONSE DYNAMICS

반응 기반 증류와 Softmax 온도(T)의 수학적 증명

교사 모델의 로짓 $z_t$와 학생 모델의 로짓 $z_s$에 온도 $T$를 적용하여 평탄화된 확률 분포 $q$를 생성합니다:

$$q_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$
$$\mathcal{L}_{KD} = (1 - \alpha)\mathcal{L}_{CE}(y, \sigma(z_s)) + \alpha T^2 \mathcal{D}_{KL}(q_t \,||\, q_s)$$

왜 $T^2$ 스케일링이 필수적인가?
KL 발산에 대한 학생 로짓 $z_{s, i}$의 편미분을 전개하면:

$$\frac{\partial \mathcal{D}_{KL}}{\partial z_{s, i}} = \frac{1}{T} (q_{s, i} - q_{t, i}) \approx \frac{1}{T} \left( \frac{1 + z_{s, i}/T}{N} - \frac{1 + z_{t, i}/T}{N} \right) = \frac{1}{N T^2} (z_{s, i} - z_{t, i})$$
  • 온도 $T$가 증가할수록 그래디언트의 크기가 $\frac{1}{T^2}$ 비율로 급격히 감쇠합니다.
  • 손실 함수에 $T^2$를 곱해주어야 하드 레이블 손실($\mathcal{L}_{CE}$)과의 크기 균형이 유지됩니다.
  • $T \to \infty$ 극한에서 KD 손실은 로짓 간의 평균 제곱 오차(MSE, $L_2$ Loss)와 수학적으로 완전히 일치합니다.
🧬
PILLAR 2: REPRESENTATION MATCHING

특징(Feature) 및 관계(Relation) 기반 기하학 보존

신경망의 최종 결과뿐 아니라 중간 은닉층의 매니폴드 구조를 직접 전이하여 학생 모델의 표현 공간을 구축합니다.

$$\mathcal{L}_{Hint} = \frac{1}{2} \| W_r \cdot \Phi_s(x) - \Phi_t(x) \|_2^2$$
$$\mathcal{L}_{RKD\text{-}dist} = \sum_{(i,j)} l_{\delta} \left( \frac{\|\Phi_s(x_i) - \Phi_s(x_j)\|}{\mu_s} - \frac{\|\Phi_t(x_i) - \Phi_t(x_j)\|}{\mu_t} \right)$$
  • 차원 변환 투영 ($W_r$): 학생과 교사의 은닉 차원이 다를 때 $1\times 1$ 컨볼루션이나 선형 사영으로 차원을 일치시킵니다.
  • 거리 보존 (Distance-wise): Huber 손실($l_{\delta}$)을 적용하여 미니배치 내 임의의 두 샘플 간 정규화된 유클리드 거리 비율을 보존합니다.
  • 각도 보존 (Angle-wise): 세 개 샘플(Triplet)이 형성하는 코사인 유사도 각도를 일치시켜 교사 모델의 위상 공간을 복제합니다.
⚡
PILLAR 3: LLM & REASONING DYNAMICS

순방향 KL vs 역방향 KL과 온폴리시(On-Policy) 증류

생성형 언어 모델 증류에서는 목적 함수에 따라 학생 모델의 텍스트 생성 양상이 근본적으로 갈라집니다.

$$\text{Forward KL}: \mathcal{D}_{KL}(P_t \,||\, Q_s) = \sum_x P_t(x) \log \frac{P_t(x)}{Q_s(x)}$$
$$\text{Reverse KL}: \mathcal{D}_{KL}(Q_s \,||\, P_t) = \sum_x Q_s(x) \log \frac{Q_s(x)}{P_t(x)}$$
  • Forward KL (Zero-Avoiding): 교사가 조금이라도 확률을 둔 영역에서 학생의 확률 $Q_s(x) \to 0$이면 무한대의 페널티가 발생합니다. 학생이 모든 모드를 덮으려다 텍스트가 흐릿해지고 환각이 증가합니다.
  • Reverse KL (Mode-Seeking): 학생이 생성한 토큰($Q_s$)을 기준으로 평가하므로, 교사의 가장 유력한 정답 모드에 집중하여 날카롭고 논리적인 문맥을 유지합니다.
  • 온폴리시 증류(On-Policy KD): 학생이 직접 샘플링한 시퀀스에 대해 교사의 피드백을 받아 궤적을 수정하는 현대 강화학습식 증류 기법입니다.
🧩
PILLAR 4: CAPACITY GAP & REGULARIZATION

용량 불일치(Capacity Gap) 해소와 자기 증류(Self-Distillation)

교사 모델이 지나치게 거대하면 학생 모델의 표현 용량을 초과하여 증류 성능이 오히려 저하되는 역설이 발생합니다.

$$\text{TAKD}: \text{Teacher} \xrightarrow{\text{Distill}} \text{Assistant} \xrightarrow{\text{Distill}} \text{Student}$$
$$\text{Born-Again}: f^{(k+1)} \leftarrow \text{Distill from } f^{(k)} \quad (\text{Architecture } \mathcal{M}_k \equiv \mathcal{M}_{k+1})$$
  • 조교 증류 (Teacher Assistant KD): 중간 크기의 중간 매개 모델(TA)을 거쳐 지식을 단계별로 희석 전이하여 수용성을 확보합니다.
  • 자기 증류 (Born-Again Networks): 동일한 크기와 구조의 신경망을 교사로 삼아 반복 증류할 때, 파라미터 규제 효과로 원본 모델보다 우수한 성능을 달성합니다.
  • Dark Knowledge의 레이블 스무딩 효과: 극단적인 확률(0 또는 1)로 인한 과적합을 차단하고 결정 경계(Decision Boundary)를 매끄럽게 교정합니다.

모델 구조 자유도 완전 자유 (레이어 수, 은닉 차원, 메커니즘 변경 가능) 동일 구조 유지 (비트 폭만 변환) 동일 구조 유지 또는 채널 수 축소 (구조적 가지치기) 동일 차원 구조 유지 (순위 $r$ 축소)
재학습 요구 여부 필수 (데이터셋 기반 역전파 학습 진행) PTQ는 불필요, QAT는 미세 조정 필요 정확도 회복을 위한 미세 조정(Fine-tuning) 필요 SVD는 불필요, LoRA는 어댑터 학습 필요
하드웨어 가속 의존도 없음 (소형 표준 구조이므로 모든 칩셋에서 즉시 가속) 높음 (INT4/INT8 하드웨어 텐서 코어 지원 필수) 비구조적 가지치기는 희소 가속기 없으면 속도 향상 미미 선형 결합 후 일반 엔진에서 실행 가능

결합 시너지 최고 (증류된 학생 모델에 양자화와 가지치기를 추가 적용) 증류 후 양자화(QAT) 적용 시 극대화 가지치기 후 지식 증류로 정확도 복구 대규모 언어 모델 서빙에 병용
PYTORCH IMPLEMENTATION

지식 증류 표준 손실 함수 파이토치 구현.

온도 스케일링($T^2$), KL 발산, 그리고 특징 사영 계층을 완벽하게 벡터화한 파이토치(PyTorch) 실전 코드입니다.

distillation_trainer.py 
# =======================================================================
# Standard Knowledge Distillation Loss & Trainer Loop (PyTorch 2.x)
# Based on Hinton et al. (2015) and FitNets (Romero et al., 2015)
# =======================================================================

import torch
import torch.nn as nn
import torch.nn.functional as F

class KnowledgeDistillationLoss(nn.Module):
    """
    수식: L_total = (1 - alpha) * L_CE + alpha * (T^2) * KL_Div
    """
    def __init__(self, temperature=4.0, alpha=0.7):
        super().__init__()
        self.temperature = temperature
        self.alpha = alpha
        self.ce_loss = nn.CrossEntropyLoss()
        self.kl_loss = nn.KLDivLoss(reduction="batchmean")

    def forward(self, student_logits, teacher_logits, labels):
        # 1. 정답 하드 레이블 교차 엔트로피 손실
        loss_ce = self.ce_loss(student_logits, labels)

        # 2. 온도 T를 적용한 소프트 타깃 KL 발산 계산
        p_student = F.log_softmax(student_logits / self.temperature, dim=-1)
        q_teacher = F.softmax(teacher_logits / self.temperature, dim=-1)
        
        # 그래디언트 크기 보존을 위해 반드시 (T^2)를 곱함
        loss_kd = self.kl_loss(p_student, q_teacher) * (self.temperature ** 2)

        # 3. 가중 합성 손실
        total_loss = (1.0 - self.alpha) * loss_ce + self.alpha * loss_kd
        return total_loss, loss_ce.item(), loss_kd.item()

class FeatureProjectionHead(nn.Module):
    """은닉 표상(Hint) 차원 불일치를 해결하는 1x1 선형 사영 계층"""
    def __init__(self, student_dim, teacher_dim):
        super().__init__()
        self.proj = nn.Linear(student_dim, teacher_dim)

    def forward(self, student_hidden, teacher_hidden):
        proj_student = self.proj(student_hidden)
        return F.mse_loss(proj_student, teacher_hidden)

# --- 단일 에폭 훈련 함수 ---
def train_one_epoch(student, teacher, dataloader, optimizer, criterion, device):
    student.train()
    teacher.eval() # 교사는 가중치 고정 (No backprop)

    for x, y in dataloader:
        x, y = x.to(device), y.to(device)

        with torch.no_grad():
            teacher_logits = teacher(x)

        optimizer.zero_grad()
        student_logits = student(x)
        loss, ce_val, kd_val = criterion(student_logits, teacher_logits, y)

        loss.backward()
        optimizer.step()
